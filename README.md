## 🚀 Cara Menjalankan Website

Website ini dibuat menggunakan teknologi **Pure Web Standalone (HTML5, Tailwind CSS, Vanilla Modern ES6 JavaScript, Lucide Icons)** sehingga **100% langsung dapat dijalankan tanpa perlu instalasi Node.js, npm, atau server rumit**:

1. Cukup klik ganda (double-click) file `index.html` pada File Explorer, atau
2. Klik kanan `index.html` -> Pilih *Open with* -> Google Chrome / Microsoft Edge / Mozilla Firefox.
3. Untuk deployment online gratis: Cukup unggah folder ini ke **GitHub Pages**, **Vercel**, atau **Netlify**.
